# API 接入指南

## 快速开始

掌柜智库提供 RESTful API，所有接口均以 `/api` 为前缀，返回 JSON 格式。接入前需在企业控制台「开发者设置」中创建应用并获取 API Key。

## 鉴权方式

API 采用 Bearer Token 鉴权方式：在 HTTP 请求头中携带 `Authorization: Bearer <API_KEY>`。API Key 分为测试环境与生产环境两类，测试环境 Key 仅能访问沙箱知识库。API Key 泄露后可在控制台即时吊销并重新生成，吊销后原 Key 立即失效。

## 核心接口

### 问答接口

`POST /api/ask` 为核心问答接口，请求体包含 `query`（用户问题，必填）与 `top_k`（返回引用条数，默认 5）两个参数。响应包含 `answer`（答案文本）、`citations`（引用列表，含来源文档、标题路径与原文片段）与 `refused`（是否拒答）字段。

### 文档管理接口

`POST /api/documents` 用于上传文档，支持 multipart/form-data 与直传对象存储 URL 两种方式。`DELETE /api/documents/{id}` 用于删除文档，删除后该文档相关的所有向量与图谱数据会在 5 分钟内同步清除。

## 请求频率限制

API 请求频率限制按 API Key 维度计算：测试环境 10 次/分钟，生产环境 120 次/分钟。响应头中的 `X-RateLimit-Remaining` 字段返回剩余可用次数。请求超限后接口返回 429 状态码，建议客户端实现指数退避重试。如需更高配额，请联系商务申请企业级限流扩容。

## 错误码

常见错误码：401（鉴权失败，检查 API Key）、403（无权限访问目标知识库）、404（文档或知识库不存在）、429（请求频率超限）、500（服务内部错误，可通过请求头中的 `X-Request-Id` 联系技术支持定位）。
