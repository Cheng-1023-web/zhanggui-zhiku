# 数据安全白皮书

## 传输与存储加密

掌柜智库全链路启用 TLS 1.3 加密传输，禁止明文 HTTP 访问。静态数据采用 AES-256 加密存储，密钥由企业密钥管理服务（KMS）托管，支持客户自管密钥（BYOK）模式。向量数据库与图数据库中的业务数据与元数据实施逻辑隔离，不同企业的知识库相互不可见。

## 访问控制

系统采用最小权限原则进行访问控制：生产环境的运维操作需通过堡垒机并双人复核；数据导出操作默认关闭，开启后需管理员审批并全量记录审计日志。问答链路中的大模型调用默认部署在私有推理网关之后，文档内容不会发送至第三方公有模型服务，企业版可通过配置项完全关闭云端模型调用。

## 审计日志

审计日志记录所有敏感操作，包括文档增删、权限变更、API Key 管理与数据导出。审计日志不可篡改，保存期限默认 180 天，企业版可延长至 3 年并导出至企业自有日志平台（支持 Syslog 与 Kafka 两种推送方式）。审计日志配置入口位于控制台「安全中心 → 审计设置」，可按操作类型与人员范围配置记录粒度。
