# 计费说明

## 版本与价格

掌柜智库目前提供免费版、专业版与企业版三个版本。

免费版面向个人用户与小型团队试用，支持导入最多 50 份文档，知识库总容量 200MB，每月提供 500 次问答额度。免费版不支持私有化部署与单点登录（SSO）。

专业版按年订阅，价格为每知识库每年 9,800 元，文档数量上限提升至 2,000 份，容量 20GB，问答次数不限。专业版包含全部核心功能，支持 API 接入与 Webhook 消息推送。

企业版采用按需报价模式，在专业版能力之上增加私有化部署、SSO 单点登录、审计日志导出、专属技术支持与 SLA 保障（99.9% 可用性）。企业版起售价为每年 50,000 元，具体价格依据知识库规模与部署方式核定。

## 计费方式与规则

企业版的计费方式为按年订阅加超量计费两部分：订阅费覆盖约定容量的知识库与不限量问答；超出约定容量的部分按每 GB 每月 30 元计费。问答次数不设上限，但单知识库并发请求数默认限制为 50 QPS，超出部分可购买并发扩容包。

所有版本均支持随时升降级：升级即时生效并按剩余天数差价补收，降级在当前订阅周期结束时生效。订阅到期后知识库进入 30 天宽限期，宽限期内可读不可写，逾期未续费数据将归档保留 90 天后删除。

## 退款政策

专业版与企业版支持 7 天无理由退款；因私有化部署已产生的实施费用不在退款范围内。退款将原路退回至付款账户，5-10 个工作日到账。
